# html-css-fundamentals

A personal portfolio website showcasing my journey from aerospace and automotive manufacturing to web development. This project demonstrates the fundamentals of HTML and CSS through a modern, animated single-page design.

## 🌐 Live Website
**Visit my website:** https://dlkilfaba-cmyk.github.io/html-css-fundamentals/

---

## 📋 Project Description

This is a portfolio website for Darren Knuckles, featuring:
- Animated starfield background with CSS gradients
- Flying airplane animation with banner
- Interactive navigation with dropdown details
- Responsive profile card with glassmorphism effect
- Clean, semantic HTML5 markup
- Externalized CSS following best practices

## 🚀 Features

- **Responsive Design**: Mobile-first approach with breakpoints for different screen sizes
- **CSS Animations**: Complex keyframe animations for visual effects
- **Semantic HTML**: Proper use of HTML5 semantic elements
- **Accessibility**: Alt text for images and ARIA-compliant markup
- **Modern CSS**: Uses flexbox, gradients, backdrop-filter, and CSS animations
- **Clean Code**: Separated concerns with external stylesheet

## 💻 Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/dlkilfaba-cmyk/html-css-fundamentals.git
   cd html-css-fundamentals
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - No build process or dependencies required
   - Works with any modern browser (Chrome, Firefox, Safari, Edge)

3. **Local Development**
   - Use any local web server (e.g., Live Server in VS Code)
   - Or use Python's built-in server:
     ```bash
     python -m http.server 8000
     ```
   - Then visit `http://localhost:8000`

## 🎨 Design Highlights

### Animations
- **Starfield Background**: Animated radial gradients creating a space-like effect
- **Flying Airplane**: SVG-based airplane with banner flying across the screen
- **Blinking Warning Light**: Keyframe animation on the airplane's warning light
- **Banner Wave**: Subtle waving effect on the trailing banner
- **Navigation Glow**: Synchronized glow effect when airplane passes over navigation items

### Responsive Features
- Navigation boxes adapt to mobile screens (< 600px)
- Profile card adjusts layout for small screens (< 520px)
- Flexible image sizing and positioning
